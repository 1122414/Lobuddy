# Lobuddy 陪伴学习与工作方式升级

## 她如何了解你

正常聊天中明确的普通偏好会显示「记住了 · 撤销」，可以在「记忆 → 她记住的我」查看来源、修改和遗忘。引用、假设、一次情绪和助手自己的话不应变成长期事实；推测需多次独立证据和确认，敏感内容也保留确认。遗忘默认保留历史聊天，可单独选择删除来源聊天；这不等于删除服务商记录、DSH 执行记录或已有备份。

明确纠正优先。觉得她话多时，可以说「以后回答简短一点」「别一直追问」「先听我讲」。这些偏好会进入后续上下文；实际表达是否自然仍需要体验，不能靠等级或自动评分证明。

「记忆」中的相处学习开关控制关系记忆；「设置 → 后台学习」是整个后台学习的总开关。总开关关闭后不再进行后台提取或工作流提议。状态页显示有效消费者、任务、失败原因与当天剩余预算。后台等空闲后工作，新的对话和语音优先；模型调用失败不会无界重试。

## 主动气泡与安静边界

她可以引用真实保存的短记忆或专注记录发出邀请，没有可靠记录时只用普通邀请。默认每天最多三次、间隔一小时，忽略后安静两小时，专注、输入、对话和免打扰时不主动闲聊。

气泡的「稍后」暂缓当前话题，「不再提」持久屏蔽该主题；在「记忆 → 共同经历与主动话题」可以恢复。相同来源版本七天内不重复，新的相关记录可重新出现；已屏蔽主题不会因为新版本自动恢复。主题匹配目前依赖保存的主题键，不能保证识别所有同义说法。

## 两个可以直接运行的办事场景

在「技能 → 工作方式与进化记录 → 运行受控办事场景」填写输入。

- 文件分类副本：路径位于当前工作区内，先展示完整复制清单，审批后按扩展名创建副本。保留原文件、不覆盖同名文件，检查数量与 SHA-256。当前支持本层最多 100 个普通文件、每个不超过 5MB、批次不超过 32MB。子目录需单独指定。失败可能留下部分副本，请先检查，不会自动重放未知写操作。
- 资料归纳：每行一个 UTF-8 文件路径或公开链接，最多六个。输出带来源编号的原文摘录、明确决定和待办；缺失来源标为未知。这里的验证证明来源与摘录关系，不保证摘要涵盖所有语义，也不支持需要登录的网页。

也可以自然语言请求她调用这些能力。任务页把「执行结束」与「结果已验证／验收未通过／结果未验证」分开，展开后查看具体条件与证据。普通聊天不计为技能成功，读取技能也不等于技能产生了效果。

## 她会如何自修改

真实任务结果可以生成带来源的待审技能候选。技能管理保留完整可恢复版本、适用条件、步骤、结果检查和失败反例；停用后新任务不能再读取。缺失的旧版本不会凭空补造。

工作流版本是不可覆盖的声明式定义。后台可以提出新候选，界面展示差异、来源、固定评测和观察次数。10.16 第一批自动晋升只开放**上下文无损格式压缩**：字段全部保留、权限不变、36 个保留场景通过、格式字节减少才启用。它节省格式开销，不代表模型突然具备新的推理能力。其他语义提示和工具步骤修改保持待评审，不用模型自评分代替独立证据。

启用后观察五次适用运行，出现回归或中断可回退；也可以点击「否定这次改变并回退」。回退作用于后续运行，不撤销已发生的文件操作。自动启用工作方式不会自动替你派发任务，实际写文件依然需要现有审批。
