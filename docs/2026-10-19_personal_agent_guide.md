# Lobuddy 10.19：持续相处与托付使用说明

## 先知道当前验收范围

新版提供持续委托、提醒收件箱、项目近况、安静边界和有证据的方法改进。N4 真人语音自然性、十轮外放/耳机、回声与延迟仍待体验验收；自动检查不代替这些结果。后台任务两小时已通过；连续语音两小时目前因测试窗口隐藏中断而未通过。完整阶段状态见 `plan_/10.19/2026-10-19_lobuddy_personal_agent_upgrade_plan.md`。

## 开始使用

本地 macOS arm64 `.app` 内含 Python、DSH 与本地语音依赖，可搬离开发目录启动。不含 API Key、聊天数据或开发目录 `.env`；不要求安装 PySide6 或 nanobot。开发源码仍保留旧 UI 兼容，未把旧代码清理当作交付条件。

打开设置，填写模型地址、模型名，通过凭据入口存入 Keychain。语音使用已经选定的声音；免费 Fish 档保持当前选择，不自动替换声音。识别模型由你在语音设置中主动下载，未下载时文字仍可用。首次开麦由系统授权；关闭语音会释放设备。

本地包尚未签名、公证或公开发布。不承诺其他操作系统、Intel Mac 或关机期间执行。

## 最近与我们

创建项目后，在聊天上方选择它。两个同名项目仍是不同对象；切换项目会重建后续引擎上下文。通过粘贴、选文件、提交链接分享材料，明确选择本次会话或某项目；不会后台监听剪贴板或读取其他应用。

决定、待办、共同经历和近况都有来源。近况需要到期时间；文件变更后停止使用旧摘录，重新分享即可。链接是分享时的快照并有期限，不自动监控网页更新。遗忘会清除正文及派生使用，保留防重复执行的最小标识；聊天历史是否删除仍是单独操作。

## 托付给她的事

创建草稿并检查目标、范围、时间、时区和授权有效期，再确认。聊天中明确提到提醒后，可以点击按钮带入原消息；不会猜“周五晚上”的具体小时。提醒需要明确时间或事件后才能确认。

在“何时开始”可选择指定时间、专注自然结束、下次回到窗口或指定委托完成；只响应确认之后的新事件。修改旧提醒保留原时区，不随当前电脑时区改变。

委托可暂停、取消、修改或查看每次执行的结果证据。文件整理仍需审批，只生成副本；执行完成与目标验证成功分别显示。取消不撤回已发生的外部效果。

关闭窗口后可以托盘常驻；明确退出会停止执行。退出时提示未结束委托，可选择保持托盘。睡眠/关机不会执行：恢复后，一次提醒在24小时内补一次并标注延迟，超期进入待查看；周期漏次合并，过期写操作不自动重放。未知写结果先核对真实产物。

## 陪伴和通知

“先听我讲”改变当前接话方式；“今天不聊工作”安静到 Asia/Shanghai 当天结束（面板会明确显示）；“以后别提”形成可管理的长期边界。这些不会擅自取消已授权任务。

气泡只引用仍有效的来源。生成失败、预算不足或无可靠资料时用普通邀请或安静；固定开场/收尾配合来源摘录，不伪造共同经历。设置保持每日3次、至少间隔60分钟、忽略后冷却2小时和主题7天去重。

明确提醒、任务结果进入通知收件箱，专注/免打扰/语音对话中先保留，允许展示后合并提示。已展示不等于你已读；打开通知后可明确标记。

## 工作方式如何改变

资料归纳目前是有引用的原文摘录，不能保证语义总结完整性。首次任务若重复读取同一本地资料，会留下真实记录；空闲学习可据此提议“本次任务复用未变更来源”。模型只提出候选，固定隔离评测决定是否启用；链接不缓存，不省略不同来源。

在学习与进化里可查来源证据、完整差异、读取次数、观察期及回退。自动启用后观察5次适用运行，回退影响后续任务。自动改进工作流不授权它自行办事。

每日后台上限仍是30次调用、60000输入和8000输出token；方法提议单次预留2048输出，其余辅助调用1024，先预留再执行，重启不清零。失败或额度不足保留状态，不进行无界重试。

## 备份、升级和回退

真实资料升级前退出应用，使用现有 `core.storage.upgrade_backup.create_backup` 创建新目录备份。它使用 SQLite 一致性快照，覆盖数据目录、外观、DSH记录及工作区里的 skills、memory、USER/SOUL/SYSTEM/AGENTS 文件；**不复制任意工作目录或外部分享文件**。那些资料留在原位置，需要时自行另行备份。

恢复使用 `restore_snapshot` 写入新目录，不覆盖当前资料。回退必须同时使用对应旧程序和升级前数据，不让旧程序直接写新版库。真实个人库尚未在本轮被自动迁移；合成库已验证重复初始化、初始化中断后恢复和备份还原。

## 本地验证入口

- `PYTHONPATH=. .venv/bin/python -m pytest tests/`
- `npm test --prefix desktop` 与 `npm test --prefix bridge/dsh`
- `node desktop/tests/delegations-smoke.cjs`、`scheduling-smoke.cjs`、`projects-smoke.cjs`、`dialogue-smoke.cjs`
- `npm run package --prefix desktop`；`node desktop/tests/package-smoke.cjs`
- `lobuddy-health --data-dir <应用数据目录> --workspace <工作目录>`：只读检查DSH、插件、已有数据库与有效模型设置；不初始化旧UI、不迁移数据、不访问模型。源码默认路径来自本机配置，检查安装版资料时需明确提供对应目录。
- `node desktop/tests/runtime-soak.cjs` 默认7200秒；短时运行报告不算两小时验收。
- `LOBUDDY_PACKAGE=<app>/Contents/MacOS/Lobuddy LOBUDDY_VOICE_SOAK_SECONDS=7200 node desktop/tests/voice-smoke.cjs`：使用已准备的合成音频与本地识别模型，透明不可交互测试窗口、隐藏Dock入口并静音输出，隔离数据，持续验证音频帧、真实模型/Fish、后台任务、RSS与退出进程；不使用真实麦克风。重复运行需用 `LOBUDDY_VOICE_SOAK_REPORT` 指定新的报告文件，避免覆盖历史证据。

真实模型脚本需要本机凭据；真人连续语音必须记录设备、网络、样本和实际延迟，不能用合成音频或模型自评分替代。
