# T2：统一契约、业务进程与工作区验证

日期：2026-10-21。前序提交：`8877486`。本阶段未切换桌面默认 Python 业务服务，未迁移真实用户数据库。TS 业务进程只声明已实现的 `service.health`，明确返回引擎未连接；110 个方法具备契约不代表 110 个业务实现完成。

## 交付

- npm workspaces、一个根锁文件、四个 strict TS 包；保留现有 React 布局与 DSH 插件。安装禁止通用生命周期脚本，Electron 原生安装显式调用锁定版本安装器。
- 119 个模型与 110 个请求/响应 Zod 契约；988 个旧 Pydantic 输入样例及默认值逐项对照。请求类型区分输入和规范化输出，包含 Unicode 码点长度、Python strip 差异、额外字段拒绝及安全整数检查。
- 协议 v2：实例 UUID、能力握手、可信边界校验、有限请求缓存、超时不重放、事件缺口触发状态重读、关闭传播取消。
- 独立 Node worker 与 Electron utilityProcess 入口；领域包不依赖 Electron。语音包本阶段仅引用共享契约，完整实现属于 T8。
- 工作区依赖复制按 Node 实际解析图保留版本隔离；独立目录内相对链接，不依赖开发目录的 hoisting。
