# P0：旧版运行基线恢复与验证

日期：2026-10-16。分支：`codex/lobuddy-dsh-rebuild`。Python 3.12.13 / macOS arm64。

## 改动与来源

四个技能模块从本仓库其他 ref 的 `a2d51c2` 恢复：schema、selector、candidate_extractor、validator。schema 仅取当前调用需要的类型，未合入后续评估系统。新增回归测试验证凭据脱敏、生成格式和危险候选拒绝。

nanobot 保持 gitlink `04a41e31ac421c00f62d971867c04c2a1ec8ec68`，未更新版本。声明直接使用的 Markdown/loguru；pynput 作为 hotkeys 可选依赖；dev 增加 pytest-cov。macOS/Python 3.12 的完整开发依赖锁定于 `requirements-dev-macos.lock`，其本地 editable 来源使用相对路径。

忽略规则改为 `/skills/`，使 `core/skills/` 新源码可正常跟踪。移除已跟踪字节码和生成的画像备份的索引记录，保留本机文件，不读取或删除用户画像内容。新增最小 macOS CI；远端 CI 尚未执行。

## 重建环境

在 macOS arm64 / Python 3.12 下，从项目根执行：

```bash
git submodule update --init lib/nanobot
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-dev-macos.lock
.venv/bin/python scripts/smoke_legacy_startup.py
```

P0 的退出标准是恢复运行和技能验证、明确既有失败，不是声称全仓质量门禁已通过。DSH、连续语音和新版 UI 均尚未实施。
