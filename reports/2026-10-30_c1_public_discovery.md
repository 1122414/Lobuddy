## Why

先用少量官方发布建立可靠的新内容入口，再由 C2 接入与近况相同的选题和接话流程。当前不自动访问发布正文里的链接、不下载附件、不执行正文指令。来源只接受 owner/repository，不接受 URL、Token 或私有账户配置。

GitHub 官方说明公开 Releases 可以匿名读取；匿名额度按来源 IP 计算，每小时 60 次。本机应用的每日六次上限不能代表这个出口还有可用配额。[Releases API](https://docs.github.com/en/rest/releases/releases#list-releases)、[速率限制](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。

独立连接器读取的官方元数据：AIRI v0.14.0 发布于 2026-10-29T18:31:04Z；ComfyUI v0.43.0 发布于 2026-10-27T02:40:46Z。N.E.K.O. 近期组件被标记为 prerelease，其旧正式版本不属于七日新鲜内容。连接器核对不算产品匿名网络路径通过。[AIRI 发布](https://github.com/moeru-ai/airi/releases/tag/v0.14.0)、[ComfyUI 发布](https://github.com/Comfy-Org/ComfyUI/releases/tag/v0.43.0)、[N.E.K.O. 发布](https://github.com/Project-N-E-K-O/N.E.K.O/releases)。

## Risks

- C1 尚未完成全部验收，未提交阶段完成 commit；B2/C2/D/E/F 的门槛保持打开。
- 首版来源为公开 GitHub Releases，不是全网新闻搜索；兴趣暂作用户配置，语义关联与自然表达属于 C2。
- 匿名 API 会受共享出口额度影响；无凭据回退。六次上限是来源读取尝试，每次最多四个 HTTP 请求（含跳转），并非预留了上游的六个请求。断网/限额时保留仍有效缓存，继续遵守已预留间隔，不无限重试。
- 没有测量多日自然陪伴、物理语音、操作系统返回事件或连续两小时稳定性。当前工程/组件结果不替代这些门槛。
