# P5：助手能力、数据与凭据升级

日期：2026-10-16；macOS arm64；DSH SDK/runtime 0.1.5rc1。沿用 P0–P4 的真实引擎和桌面链路。

## 交付内容

- Python 继续权威管理成长、五维个性和七项能力记录。结算表、技能实际使用表、用量表和迁移记录使用版本化 schema 2；重复任务和重复用量事件不重复奖励。取消、失败、中断与成功分开处理，超时显示为失败。个性数值仅影响表达，明确偏好和边界优先。
- 新增成长与设置页面。保留旧配置的可发现入口，模型、预算、历史检索等设置在重启后应用；未来桌宠视觉项和旧引擎专属项明确标为兼容设置。密钥只显示配置状态，输入使用 macOS 原生隐藏输入框，Python 写入 Keychain。
- Electron 主进程通过原生选图获得路径；普通业务 IPC 禁止 renderer 直接调用图片导入。Python 检查普通文件、魔数对应格式、真实解码、尺寸和大小，保存私有内容寻址附件；界面只使用附件 ID 与小预览。DSH 公共 `ctx.attachments.saveImage` 验证并持久化附件，再交给模型。保留图片历史。默认模型 `deepseek-flash` 已实测图片理解，不要求另填图片模型密钥。
- macOS 本地候选查找与打开不依赖 nanobot。查找范围为工作区顶层、桌面和应用程序目录；打开必须命中本轮候选并通过审批，执行前检查文件未变化。旧 LocalOpenTool 兼容入口复用原生打开实现。
- 增加受控基础文件命令、网页读取和网页搜索。命令使用参数数组、最小环境、审批、预算、路径检查和独立进程组；取消会清理当前轮工具进程。HTTP(S) 检查公网地址并固定实际连接 IP，重定向逐跳检查，不携带 cookies 或认证。搜索使用公开 Bing RSS，要求有真实结果项和来源链接，外部页面作为不可信资料处理。
- 增加 `python -m app.upgrade`：backup / verify / import / restore / credentials。SQLite online backup 保留 WAL 已提交内容；运行时停止后备份 DSH 会话文件；私有快照有完整校验清单。导入到新目录、保留 ID、迁移技能正文与路径，重复导入无变化；原始库保持可回退。旧入口拒绝打开升级库。

## 依赖、资源与边界

新增 `@deepseek-ai/dsh-attachment@0.1.5-rc.1` 作为与运行时匹配的官方类型依赖，MIT；不另引图片传输框架。Keychain 使用系统 Security/CoreFoundation，Pillow、dotenv 与 HTTP/标准库均沿用现有依赖。

基础命令仅开放 `ls/cat/head/tail/wc/pwd/echo/mkdir/touch/cp/mv/rm` 的受控参数。递归删除、解释器、包安装、任意 Shell 语法和 Git 副作用未开放；图片、网页和应用打开通过专用工具。保留代码生成与文件编辑能力，不声称具备 Codex 等价的任意代码执行能力。搜索服务可能限流或阻断；遇到无结果/错误明确失败，不伪造检索结果。

图片与服务设置页面见 [图片](assets/p5-image.png)、[成长](assets/p5-progress.png)、[设置](assets/p5-settings.png)。旧图片路径若不在备份内，不能凭空恢复；本机旧库没有此类引用。停用旧技能若历史正文已丢失仍需原始备份，P4 已明确说明。

本机私有演练目录：`.local-upgrade/2026-10-16-p5-backup`、`2026-10-16-p5-import`、`2026-10-16-p5-restored`。已忽略，不进入提交。原始库仍是 schema 0。真正切换默认数据目录、独立打包和整机回退启动演练在 P9 完成；本阶段没有把开发包宣称为独立发行包。

Keychain 迁移后，`.env` 继续保存模型名、地址和非秘密配置。旧提交程序不认识 Keychain；回退到历史提交时应由受信任启动器在内存中向旧进程提供凭据，或重新使用旧版受支持的凭据配置流程；不得把升级库直接交给旧程序。
