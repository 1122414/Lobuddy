# P3 新版桌面与文字闭环

日期：2026-10-16。P3 验收通过。

## 改动与边界

Electron + React + TypeScript + Vite 桌面应用提供会话、Markdown 流式回复、前后台任务模式、任务页、取消、审批弹层。实际会话自动使用第一条消息作为默认标题。主进程持有 Python 服务，渲染进程刷新或关闭不重新提交任务；重新打开窗口读取真实 SQLite 历史。此阶段开发包依赖当前 checkout/Python；P9 才提供独立安装。旧 Qt 入口保留。

依赖固定：Electron 44.8.0、React/ReactDOM 19.3.1、Vite 8.3.4、TypeScript 7.0.2、react-markdown 10.1.0、Playwright 1.64.1。前三者为用户批准的架构；react-markdown 用于禁用原始 HTML 的 Markdown 渲染，Playwright 用于实际 Electron 自动化回归。运行依赖均 MIT，Playwright Apache-2.0；npm install --ignore-scripts 后单独运行官方 Electron 安装器；npm audit 返回 0 vulnerabilities。

## 视觉核对

使用 frontend-app-builder 与内置 image_gen 产生[设计参考](../plan_/design_plan/10.16/assets/p3-desktop-concept.png)，提炼[实现规格](../plan_/design_plan/10.16/2026-10-16_desktop_design_spec.md)。IAB 实际打开构建预览并检查任务页与约 435px 窄窗；浏览器无法访问 Electron preload，因此原生交互使用 Playwright Electron driver。原生桌面最小宽度 900px，不将窄窗预览当作移动端发布承诺。

使用 view_image 同时查看概念和实际 Electron 截图；检查了侧栏/主栏比例、标题和正文层级、蓝绿/冷白色板、消息与任务状态、输入框与按钮、审批弹层。默认 1200×800 与 1536×1024 CSS 窗口检查，后者 Retina 截图 3072×2048。保持蓝绿侧栏、开放聊天区、固定输入框、描边图标和单行任务条；修正大窗口侧栏比例为 clamp(234px,19.53vw,300px)。文案核对无新增营销区，运行消息/标题/状态由实际数据决定。必要差异：图中光泽装饰改为用户计划的平面表面、无功能省略号不实装、系统窗口控件不作为网页元素绘制。默认空态和缺配置提示属于实际功能状态，未用假数据掩盖。

## 已解决的验收问题

- 配置曾被清空，独立 stdio 复测也失败；存在性检查和脱敏 SDK 错误定位到空模型名。恢复配置后通过，未覆盖用户 .env。
- 关闭窗口后 firstWindow 可能返回尚未移除的旧页面，测试改为等待新 window 事件；保留真实关闭/重开要求。
- 一次长文用例未在 90 秒内出现可取消的可见文本；改用 P1 已验证的海洋长文提示，仍必须看到实际增量文本后点击取消，不降低为入队即取消。
