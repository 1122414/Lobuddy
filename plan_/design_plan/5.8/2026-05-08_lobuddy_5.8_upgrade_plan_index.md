## 总边界

5.8 的目标是把 Lobuddy 从“功能很多的桌宠 AI 助手”推进到“可维护、可审计、可扩展、用户可控的桌面伙伴系统”。

必须保持以下边界：

- AI 调用继续以 `core/agent/nanobot_adapter.py` 为唯一边界。
- 业务记忆写入继续走 `MemoryWriteGateway`。
- Skill 使用反馈在没有真实 execution hook 前不得伪造。
- 危险命令继续受 `ToolPolicy`、`SafetyGuardrails`、HITL 三层保护。
- UI 不直接写 SQLite，不保存 domain 状态。
- SQLite 继续 raw SQL + repository pattern，不引入 ORM。

5.8 明确不做：

- 不做全量 UI 重构。
- 不做全功能 RAG。
- 不做全盘文件索引。
- 不做屏幕常驻分析。
- 不做远程控制。
- 不做自动审批危险命令。
- 不做 skill marketplace 网络安装。
- 不做 skill 任意脚本执行。
- 不做多用户云同步。
- 不做 nanobot 内部大改。
