# Lobuddy 5.8 产品功能升级计划

制定日期：2026-05-08  
目标版本：5.8.x  
交付对象：opencode  
优先级：P2

## 1. 目标

在不破坏系统边界的前提下，提升用户感知：任务更透明、桌宠更有成长、Focus 更实用、本地意图更可靠。

- `core/focus/`
- `core/game/`
- `core/abilities/`

## 3. 任务优先级

### P2-E1：任务卡片 2.0

必须做：

- 任务卡片展示：
  - 用户目标。
  - 状态。
  - 简短结果。
  - 错误摘要。
  - EXP 奖励。
  - 可展开详情。
- 预留步骤结构：
  - understand。
  - plan。
  - tool_call。
  - result。
- 当前如果没有真实 step trace，可显示已有状态，不伪造步骤。

严禁做：

- 严禁让模型输出的任意 markdown 直接进入未消毒 HTML。
- 严禁把完整 raw_result 默认展示给普通用户。

验收标准：

- 成功/失败/取消任务都有清晰卡片。
- 长文本不会挤爆 UI。

预留接口：

- 后续接 ExecutionTrace 生成真实步骤时间线。

### P2-E2：桌面意图增强

必须做：

- 强化 local open typed tools。
- 重点场景：
  - 打开桌面快捷方式。
  - 打开最近项目目录。
  - 打开已知应用。
  - 打开用户确认过的文件。
- 所有打开动作必须经过 resolver candidate，不允许模型手写路径直接打开。

严禁做：

- 严禁全盘搜索 `C:\`。
- 严禁扫描 `Program Files`、`AppData`、用户隐私目录，除非用户明确配置允许。
- 严禁退回通用 shell 执行 open/start。

验收标准：

- 中文目标提取测试覆盖：
  - “打开微信”
  - “帮我打开桌面的 QQ”
  - “打开桌面上的洛克王国：世界”
- resolver -> opener candidate 链路闭合。

预留接口：

- `LocalIntentRegistry`
- 后续支持用户手动登记常用 app/file。

### P2-E3：Focus Companion 增强

必须做：

- 增加基础 focus session 记录：
  - start。
  - pause。
  - resume。
  - complete。
  - interruption count。
- UI 展示当前 focus 状态。
- 完成后生成简短本地总结，不强制写长期记忆。

严禁做：

- 严禁监控用户屏幕内容。
- 严禁记录用户打开的所有应用。
- 严禁默认把 focus 内容写入长期记忆。

验收标准：

- 测试覆盖状态转换。
- Focus 结束不会影响普通任务队列。

预留接口：

- 后续接每日回顾和用户确认式记忆写入。

### P2-E4：每日回顾 MVP

必须做：

- 基于本地任务记录生成：
  - 今日完成任务数。
  - 成功/失败数量。
  - EXP 获取。
  - 最近重点事项。
- 可选择由 AI 生成自然语言总结，但必须使用脱敏摘要。

严禁做：

- 严禁自动发送到外部服务。
- 严禁把完整聊天记录塞入总结 prompt。
- 严禁默认写入长期记忆。

验收标准：

- 无 AI key 时也能生成基础统计。
- 有 AI 时可生成总结，但失败不影响基础统计。

预留接口：

- `DailyReviewService`
- 后续可接定时提醒。

### P2-E5：宠物成长反馈增强

必须做：

- 展示：
  - 当前等级。
  - 距下一级 EXP。
  - 最近一次任务奖励。
  - 解锁能力。
- UI 反馈必须轻量，不做大型动画重构。

严禁做：

- 严禁重写 growth algorithm。
- 严禁把 UI 状态写入 domain model。

验收标准：

- 任务完成后 EXP 展示一致。
- level up 和 ability unlock 有明确用户反馈。

预留接口：

- 后续成长树、称号、成就系统。

### P3-E6：多模态能力预留

必须做：

- 只预留接口与文档说明。
- 当前图片分析能力继续保持手动上传/明确触发。

严禁做：

- 严禁默认截屏。
- 严禁后台分析屏幕。
- 严禁监听窗口内容。

预留接口：

- `VisualContextProvider`
- `UserConsentPolicy`
