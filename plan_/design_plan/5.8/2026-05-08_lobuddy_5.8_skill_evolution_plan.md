# Lobuddy 5.8 Skill 系统进化计划

制定日期：2026-05-08  
目标版本：5.8.x  
交付对象：opencode  
优先级：P2

## 1. 目标

从“skills 存在并注入 prompt”进化为“用户可审核、可测试、可启停、可维护”的技能系统，同时等待真实 execution hook 后再闭环使用反馈。

## 2. 涉及模块

- `core/skills/`
- `ui/skill_panel.py`
- `core/agent/nanobot_adapter.py`
- `workspace/skills/`
- `tests/test_skill_*.py`

## 3. 任务优先级

### P2-D1：Skill 实验室 MVP

必须做：

- 在 UI 或服务层展示：
  - skill name。
  - description。
  - category。
  - status。
  - version。
  - source。
  - last_used_at。
  - success/failure count。
  - review_after / expires_at。
- 支持：
  - enable/disable。
  - archive。
  - view content。
  - view events。

严禁做：

- 严禁 UI 直接改 `workspace/skills` 文件。
- 严禁直接删除 skill 记录；删除必须保留明确用户动作。
- 严禁自动启用 AI 生成的新 skill。

验收标准：

- SkillManager API 有测试覆盖。
- UI 或服务可列出 active/disabled/archived。

预留接口：

- 后续接入 skill marketplace 或 skill installer。

### P2-D2：Skill 候选审核

必须做：

- 将当前 `skill_candidate` 真正暴露给用户审核。
- 支持状态：
  - pending。
  - approved。
  - rejected。
  - converted。
- approved 后才创建真实 skill。

严禁做：

- 严禁模型直接写入 active skill。
- 严禁低置信度候选自动通过。
- 严禁保存包含 secret 的 skill 内容。

验收标准：

- 测试覆盖 candidate -> approved -> create_skill。
- rejected candidate 不进入 prompt。

预留接口：

- 后续可加候选来源跳转会话。

### P2-D3：Skill 测试沙箱

必须做：

- 每个 skill 可选带测试样例。
- 创建/patch 后执行静态校验：
  - 是否有 `SKILL.md`。
  - 是否有清晰触发规则。
  - 是否包含危险指令。
  - 是否包含 secret。
- 暂不执行任意脚本。

严禁做：

- 严禁运行 skill 内提供的任意 shell/python 脚本。
- 严禁自动安装外部依赖。
- 严禁从网络拉取 skill。

验收标准：

- 新增 `SkillValidator` 或扩展现有校验。
- 测试覆盖危险内容和 secret 拒绝。

预留接口：

- 后续可接受控沙箱执行 quick_validate。

### P2-D4：真实 Skill 使用反馈接口预留

必须做：

- 定义接口，不接假数据。
- 推荐事件：
  - `SkillExecutionStarted`
  - `SkillExecutionCompleted`
  - `SkillExecutionFailed`
- adapter 中只保留 TODO 或空 hook 接口，等待 nanobot 暴露可靠事件。

严禁做：

- 严禁根据 prompt 中出现 skill 名称推断使用。
- 严禁根据任务整体成功给所有 active skill 记成功。
- 严禁解析自然语言输出伪造 skill usage。

验收标准：

- 文档和测试明确：当前 skills are prompt-visible, not usage-accounted。

预留接口：

- `SkillUsageEvent`
- `SkillUsageSink`
- `NanobotSkillHookAdapter`

## 4. 跨模块边界

- active skills 可以注入 prompt。
- usage feedback 必须等待真实 execution hook。
- candidate 必须经用户审核。
