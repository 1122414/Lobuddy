# Lobuddy DSH 重构实施计划

日期：2026-10-16。执行分支：`codex/lobuddy-dsh-rebuild`。

本文件落实用户批准的实施计划。每阶段验收后一次中文 commit，不自动推送，不改写历史；已有 `10.15 → 10.16` 总纲移动保持用户原状，不纳入代码提交。

## 已确定的技术与产品决策

- Electron + React + TypeScript + Vite 替换 PySide6 界面；Python + SQLite 保留业务能力。
- macOS 14+ Apple Silicon 优先，Windows 保留兼容设计，完整验收后续进行。
- Electron preload 只暴露类型化业务操作，渲染层隔离并开启沙箱，不接触 Shell、文件系统或凭据。Markdown 禁止原始 HTML。
- Electron 主进程管理 Python 服务，stdio JSON-RPC 承载请求和事件；stdout 仅协议，stderr 日志。Python Pydantic 是协议定义来源，生成 TypeScript 类型。
- DSH 独立运行进程由匹配版本的官方 Python SDK 管理，使用独立 home；自有 TypeScript 插件通过公共 Agent API 提供会话、流式、取消、工具拦截与审批。
- 插件桥使用随机 loopback 端口、每次启动认证令牌、HTTP JSON-RPC 和 SSE；就绪信息写入私有启动文件，渲染层不获取桥接凭据。
- DSH 工具必须经过 ToolPolicy、Guardrails、预算和 HITL；拒绝、超时、桥断连时不执行。禁用未经治理的插件/工具入口及非必需日志上传。
- 前台对话与长任务隔离，最多同时一个前台对话和一个后台任务；插话只取消当前对话，已派发的任务独立取消。可能已产生副作用的操作不自动重试。
- 本地 faster-whisper multilingual small / CPU int8 + Silero VAD；首次由设置下载模型，不自动退回云识别。
- Fish 流式 PCM 合成，固定首选音色 `e4a66454f7a44f63a2cc9e8c044d701d`；不可用时提示，不暗中换声。
- 原始音频在本机内存处理；最终转写默认入历史。文字对话仍发给模型服务，回答文字发给 Fish，整个助手并非离线产品。
- 浊蒂仅沿用外形；性格随相处形成。保留五维个性，显式纠正优先于推测，长期写入统一经过 MemoryWriteGateway。

## 接口与数据契约

接口组：会话/任务（创建、切换、发送文字图片、历史、取消、状态）；记忆/技能（查询、编辑、删除、启停、更新）；宠物/专注（状态、外观、计时）；语音/设置（开启、静音、结束、音频帧、配置、健康）；审批（列表、允许、拒绝）。

请求有请求 ID；事件有会话、任务、轮次 ID 和序号。完成、失败和取消独立建模。界面刷新或断连不得重复执行任务；迟到事件不能覆盖新轮。

SQLite 是业务权威库，DSH 保存执行记录；保留原有实体 ID，新增引擎映射、版本化迁移、结算唯一性约束。凭据迁入 Keychain，失败保留旧值并报错，不回退明文。先合成数据、再备份真实库与所有投影/外观；不让旧代码打开不兼容的新库。

## 产品默认值

- 宠物层只放宠物、短气泡和状态；点击展开轻量聊天；管理窗口包含历史、任务、记忆、技能、成长、专注、设置。
- 低饱和蓝绿色、轻量半透明面板，兼容现有主题。状态：安静、倾听、思考、说话、执行、待审批、异常。
- 主动闲聊默认每天最多 3 次，间隔 60 分钟；忽略冷却 2 小时，全部可配置。专注、输入、对话、免打扰时抑制。
- 任务通知/显式提醒不占闲聊配额。只使用本应用事件和已知记忆，不默认读取屏幕或 Codex 内容。
- VAD 静音阈值初始 700 毫秒，可设置；先停止播放和旧轮音频，再取消生成。沉默不强行填话。
- 只合成面向用户的回复，不读推理、参数和工具日志。目标短句响应 P95 ≤ 4 秒、检测插话后停止播放 P95 ≤ 300 毫秒；实测未达标不能降级为逐句按键交付。

## 验证与提交纪律

每阶段执行相关 pytest、Ruff、Black、mypy；前端/插件执行类型、单测和生产构建；跨进程检查启动、断连、超时、乱序、取消、退出。模拟测试和真实模型/音频/安装包验证分别记录。

重点回归：会话隔离；拒绝/超时无动作；迟到音频不复活；重连不重复消息/经验/执行；迁移两次一致且中断可恢复；遗忘和投影同步；耳机与扬声器连续对话；两小时运行与资源清理。

检查失败先修复或报告具体阻塞，不提交完成标记。提交前检查分支、工作区、暂存差异，只含当前阶段；正文记录命令和实际结果。禁止自动 push、amend、清除用户未提交工作。

首轮交付本地可安装 macOS arm64 包，不包含签名、公证、公开发布、Linux 验收、多 Bot 群聊或 Codex 深度集成。最终移除 nanobot/PySide6 以前必须完成等价功能验收和回退演练。
