# P6 桌宠与快速聊天设计

参考：[完整概念图](assets/p6-companion-concept.png)。管理窗口延续 P3 设计，新增「专注」「外观」入口。

- 宠物层：透明窗口、不获取焦点，浊蒂 V2 原始图集，192×208 单帧，默认显示 144×156。上方短气泡，下方轻量状态。拖动角色移动，点击打开聊天。闲置不显示工具栏。
- 快速聊天：390×490 DIP，浅冷白背景，18px 圆角，1px 蓝灰边框。标题使用真实伙伴名；展开管理窗口、关闭；正文、后台任务摘要、输入和发送。图片入口仍走原生选择器。
- 配色：背景 #f8fafb，侧栏 #deebec，正文 #142c36，强调 #367572，边线 #d6e3e6。正文 15px/1.7，控件 14px，标题 20px/600，状态 12px。
- 原始图集的 idle / processing / waiting / review / failed 分别映射安静 / 思考或执行 / 倾听 / 待审批 / 异常。P8 才开放语音，不展示可点击但无行为的麦克风按钮。只沿用外观，不写入角色背景和性格。
- 动画尊重系统减少动态效果；关闭或隐藏窗口暂停动画。语音状态保留统一标识，P6 不伪造录音或说话状态。
- 透明窗口尺寸随外观缩放改变；主进程用 DIP 与屏幕 workArea 定位，移除屏幕后重新夹取到可见区域；位置只存 Electron UI 状态文件。
- 托盘提供聊天、管理、专注、显示宠物、退出。快捷键注册失败会在外观页显示，不能宣称生效。审批刷新/关闭继续拒绝，所有窗口共享同一个 Python 服务。

验收：真实 Electron 三窗口/拖动/焦点/重开/跨窗任务；几何单测覆盖负坐标、不同缩放、移除屏幕；外观和主题保存后重启恢复；专注开始暂停继续结束；原始图集无裁切。原生窗口通过 Playwright Electron 验证（此前 CUA 原生连接长期挂起）。最终截图与概念逐项比对。
