# Lobuddy 下一目标：懂你、会陪伴、能验证的自进化

日期：2026-10-16。依据用户批准的计划实施；阶段状态以验证报告和 Git 提交为准，不将已写代码等同验收完成。

## 目标与边界

沿用 Electron + Python/SQLite + DSH，建立「相处与执行 → 提取经验 → 提出修改 → 对照验证 → 自动启用或拒绝 → 持续观察与回退」闭环。陪伴和办事并重。

- 普通明确偏好、共同经历自动记住，轻提示并可撤销；推测与敏感内容确认后生效。
- 累了或烦了时先自然陪聊，不急于说教、制定任务或连续追问。
- 外形继续用浊蒂，声音保持已选音色；性格随相处形成，不预设角色背景或恋爱关系。
- 自修改限提示模板、上下文选择、已有工具组成的受控工作流。权限不扩大的低风险修改通过验证后自动启用。
- 不开放任意 Python/JavaScript、自改应用源码、修改审批规则或任意插件安装；不声称模型权重训练。
- 默认不读取屏幕、Codex 对话或其他应用，不额外接入评测服务。自动启用工作流不等于授权自动办事。

## 关系记忆与陪伴

复用 SQLite 与 MemoryWriteGateway。关系记忆从单一槽扩展为多条，记录类型、来源消息/事件、适用范围、时间与修订关系。

- 类型：明确偏好、共同经历、临时状态、推测候选。引用、假设、角色扮演和助手发言不能作为用户事实。
- 普通明确偏好自动保存，显示「记住了 · 撤销」；暂时情绪只用于当前交流。
- 推测习惯至少三个独立事件支持后才可提出确认，确认前不作为事实注入。
- 健康、财务、精确位置、私密关系不自动长期保存；明确要求记住视为该项授权。秘密永不进入记忆。
- 明确纠正优先；情境性要求不覆盖全局偏好；冲突不能确定时询问。
- 遗忘清理检索、投影、摘要和待处理派生任务，阻止历史重新生成；历史聊天是否删除单独选择。
- 结构化语义摘要保留目标、决定、纠正、未完事项和共同经历及来源。按相关性选择记忆和技能摘要，按需读取正文；失败使用近期原文。

主动策略保留每日三次、间隔六十分钟、忽略冷却两小时；专注、输入、对话、免打扰时抑制。

- 从真实记忆、未完话题、专注事件生成话题，无依据用普通邀请。同主题七天内不重复，新的相关事件除外。
- 「暂时不聊」与「以后别提」分别为临时冷却、持久边界。
- 「少说一点」「别一直追问」「先听我讲」直接作用后续表达；五维仅弱倾向，不能覆盖明确反馈。
- 增加「她记住的我」「共同经历」视图，可查看来源、修改、撤销、遗忘、关闭学习。
- 成长分为陪伴历程、表达偏好、已验证技能；保留 EXP/等级但不代表能力，纠正已可用能力显示为锁定的矛盾。

## 办事、技能与自修改

执行状态与目标验收分开：新增 verified / failed / unknown 和证据，取消不自动判业务失败。文件检查产物/路径/内容/校验值，归纳检查来源覆盖与引用；助手宣称完成不构成唯一证据。聊天不记技能成功，读取技能不构成效果归因。

从纠正、重复任务、已验证成功、有证据的失败生成技能候选，含适用条件、步骤、验证与反例。首批完整场景：

1. 文件整理：指定目录 → 分类清单/预览 → 现有审批 → 指定输出目录的分类副本 → 数量/内容验证；保留原文件、不覆盖同名文件。目录枚举和复制使用受控工具，保留路径、大小、预算、审批检查，不用任意脚本。
2. 资料归纳：用户文件/链接 → 有来源的摘要、决定、待办；来源缺失明确标注，不能用推测补全。

工作流为 Pydantic 校验的声明式 DAG，由 Python 执行。节点仅上下文选择、模型调用、受控工具、结构化条件、结果验证、输出；无 eval 或代码字符串。

- 每次固定版本，最多十二节点、两次修复，继承时间和工具预算。
- 只生成新候选，不覆盖稳定版；保存完整定义、证据、差异、评测记录。
- 合成数据、临时目录、模拟工具对照稳定版，不操作真实文件/账户。评测规则和保留答案、权限、审批、凭据、记忆网关不可自改。
- 自动晋升：全部硬性回归通过、权限不扩大、预先指定指标至少一项改善且无退化；模型评分仅辅助。无法可靠自动验证的内容保持候选。
- 启用后五次适用运行观察；权限违规、明确回归、用户否定则停用/回退。回退只影响后续，不撤销外部副作用；未知写操作不重放。

## 接口、存储与调度

延续 stdio JSON-RPC、Pydantic 生成 TypeScript：记忆候选确认/来源/修订/撤销/遗忘；话题来源/反馈/偏好/经历；任务验收；技能/工作流版本/差异/评测/启停/回退；学习开关/任务/最近执行/失败/预算。

新增关系来源与修订、验收、不可变工作流版本、评测、后台作业数据；保留原有 ID 与旧版本号，不伪造缺失历史。版本化幂等迁移，备份恢复验证。

- 应用运行且空闲六十秒后单并发；聊天/语音优先。
- 默认每日最多三十次模型调用、六万输入 token、八千输出 token；调用前预留，任一用尽暂停，重启不重置，可设置。
- 覆盖后台提取、摘要、话题、评测；前台独立。纠正立即影响当前上下文，未保存显示待处理。
- 断网、额度不足、模型失败保留待办，继续稳定版，不无界重试。
- 维护从 Qt 迁到服务，初期只报告过期/冲突/失效，不自动删除记忆/技能。有效开关与消费者、调度、最近结果可查。

## 验收

至少三十固定合成场景，含正常、反例、故障；开发样例与保留答案隔离，候选不能修改评测。

| ID | 场景 |
|---|---|
| FG-01 | 偏好跨会话；引用/一次情绪/敏感不误存；纠正、遗忘防复活 |
| FG-02 | 开关真实接线；关闭/超额/断网/重启无重复失控调用 |
| FG-03 | 长聊决定/纠正/未完可溯源；相关技能；删除不进新摘要 |
| FG-04/05 | 中文偏好作用表达；话题有据；冷却/专注安静；成长不冒充能力 |
| FG-06 | 无产物不能 verified；取消/拒绝不计成功；重复事件不重复结算 |
| FG-07 | 成败均可生成证据候选；版本/来源/反例；停用阻止后续使用 |
| FG-08 | 改善才晋升；不改善/扩权/改测试/越权拒绝；回退；未知副作用不重放 |

阶段门禁：相关 pytest、Ruff、Black、mypy；前端/插件类型检查、测试、生产构建。最终全量回归、双次迁移一致、备份恢复、两小时运行。

真实模型演示：记住 → 纠正 → 跨会话召回 → 真实经历主动话题 → 办事验收 → 修改候选 → 对照 → 启用/拒绝 → 回退。自然陪伴须实际体验；已有可听可聊反馈不替代连续十轮、外放回声和延迟验收，未完成如实标注。
