# Lobuddy 全面 TypeScript 重构实施计划

授权日期：2026-10-21。基线：`7195718`。实施分支：`codex/lobuddy-ts-rebuild`。

## 目标与固定边界

将应用迁移为 Electron + React + TypeScript + SQLite + DSH，最终开发、测试、打包、运行均不依赖 Python。允许 SQLite、ONNX Runtime、图像库及 DSH 的原生二进制。当前 UI 布局、浊蒂、Fish 音色、Jev、记忆、成长、陪伴、委托与受控进化保持功能等价。首轮验收 macOS Apple Silicon / macOS 14+。不扩展此前未迁入 DSH 的旧 main 独有功能。

保留实体 ID、来源、技能和工作流版本及执行证据。旧实现只在迁移期间用于独立数据上的开发对照；T9 从当前源码删除 Python、Qt、nanobot，Git 历史和历史报告保留。真人语音与连续语音长稳独立记录，未验收不宣称发布完成。

## 架构与依赖

React → 受限 preload → Electron 主进程 → TS 业务 utilityProcess → SQLite / DSH / Fish / Jev。另设 TS 语音 utilityProcess 执行 Silero ONNX 与 Whisper ONNX。主进程负责窗口、系统权限、凭据及进程生命周期；业务进程是唯一业务数据库写入者；领域模块不依赖 Electron。推理不阻塞主进程和业务队列。

采用 npm workspaces 和单一根锁，保留 desktop、bridge/dsh，新增 contracts（运行时 schema 与推导类型）、domain（业务规则）、service（存储、网络与服务组装）、speech（语音与模型）四包。不引入 HTTP 业务服务器、ORM、消息队列或大型后端框架，不把原千行应用类机械翻译为 TS 巨型类。

| 能力 | 固定技术 |
|---|---|
| 数据 | node:sqlite、原始 SQL、仓储；同步操作只在业务进程，维护分批执行 |
| 校验 | Zod 4.6.7；请求、响应、事件和存储 JSON 均验证 |
| 时间 | @js-temporal/polyfill 0.5.1，保持 DST 和原时区语义 |
| 图像 | sharp 0.35.5，校验、缩放、压缩及取色 |
| 网页 | htmlparser2；受控 DNS 固定连接、重定向逐跳校验 |
| 识别 | @huggingface/transformers 4.3.1 + onnxruntime-node 1.30.0；Whisper small multilingual CPU q8 |
| VAD | 固定 Silero ONNX 权重和 tensor 契约 |
| 并发 | Promise、AbortController、显式状态与所有权 |
| 测试 | Node 内置测试框架及 Playwright |

前端保持现有版本；安装前核对完整依赖、安全公告、许可证，不静默升级。已实测 Electron 44.8.0 / Node 24.22.0 支持 SQLite、FTS5、backup。

DSH 使用 @deepseek-ai/dsh-sdk-client 0.1.5-rc.1，runtime 与插件同版本锁定。TS SDK 管启动/握手/关闭；已有 loopback HTTP/SSE 插件桥继续负责取消、流式事件、审批、工具拦截。保留随机令牌、私有 ready 文件、独立 home、遥测及内置工具禁用清单。显式 dshBin 指向随包官方 macOS arm64 独立二进制。TS 下载器校验并解包官方分发物，仅带运行文件及许可，不执行 pip/Python，不依赖全局 Node/DSH/PATH；未知副作用不重放。

## 协议与业务迁移

110 个方法逐项登记参数/返回/事件/错误/幂等规则/测试。保留方法、字段、业务语义，Pydantic→TS 生成改为 Zod→类型推导。保持空值、缺省、Unicode 长度、数值范围、枚举及额外字段拒绝。内部协议升级 v2，握手含能力与实例 ID；拒绝版本不匹配。事件保留会话/任务/轮次/序号；重启或断层重新读取权威状态，不补发操作。开发可选择完整旧后端对照，不允许同一实例逐请求混用两种写后端；发布时移除旧适配器。

| 领域 | 不可丢失的行为 |
|---|---|
| 会话与任务 | 前后台队列、隔离、流式、取消、审批、恢复、完成/失败/取消/中断区分 |
| 治理 | 路径和符号链接、命令参数白名单、SSRF/DNS 固定、预算、HITL、子进程环境隔离 |
| 结算 | verified/failed/unknown、产物证据、一次性消息/EXP/统计；未知写不重放 |
| 记忆/项目 | 偏好、候选确认、来源修订遗忘、摘要检索、近况及项目隔离 |
| 陪伴/成长 | 配额冷却、忽略反馈、主题屏蔽、倾听、边界、共同经历、旧 EXP 与五维个性 |
| 技能/进化 | 版本、反例、DAG、固定评测、晋升、五次观察、停用/回退 |
| 委托 | 草稿确认、授权、周期/事件、时区、逾期策略、单执行权、持久恢复 |
| Jev | 独立预算、严格结构与置信度、失败降级、决定可查；不扩权 |
| 辅助 | 图片分析、外观主题、专注、用量、凭据、健康、备份恢复 |

任务状态、完成事件、奖励同事务。纠正/遗忘失效化摘要、技能候选、后台作业、话题、回放缓存及 DSH 映射。权限、评测、凭据、记忆网关不可自改。后台预算调用前预留、重启不重置、前台优先；保持每日 30 次/60000 输入/8000 输出上限。时区缺口跳过、重复取首次、编辑不改原时区。图片实际格式、大小/尺寸/像素与路径均验证；允许新编码字节变化，已有 ID/文件不改。

## 数据与凭据

先保留现有 SQLite 模型，汇总分散建表/索引/触发器/FTS；TS 迁移登记有顺序及校验值，保留旧版本记录。校验完整性、未知版本、实体计数与关联。保留 ID、JSON 语义、请求指纹兼容；不批量重写指纹引发重复执行。投影和 FTS 可重建，SQLite 为权威。JS 不安全整数不得截断。

升级先退出旧实例并备份，再导入新 TS 目录；不覆盖旧库。新库版本令旧桌面拒绝直接打开。临时目录校验后原子切换，中断可重试。未完成任务中断/待核对，审批失效；委托定义保留、明确展示恢复状态，不自动续跑未知写。旧新实例不得同时执行迁移前委托。TS 用独立 SQLite 锁库持有排他事务，死亡释放。

凭据在主进程 safeStorage 加密、原子写入与私有权限；失败不回退明文。从既有 com.lobuddy.desktop Keychain、显式环境/旧 .env 或旧库导入，逐字段显式配置优先。秘密不进命令参数、日志、renderer、报告。写入且读回成功才能清理，首次切换保留来源支持回退。enc:v1 只解码旧数据，不再用于保存。未签名包可能需 Keychain 再授权，记录实际结果，不自动公开签名/公证。

## 语音

模型选 onnx-community/whisper-small；固定 revision、文件清单及 SHA256，只下载 q8 所需文件。旧 faster-whisper 模型保留原目录，不直接复用格式。用户设置中明确下载；未下载文字可用。保留 16kHz/32ms、默认700ms静音、轮次隔离、有界队列。原音频仅内存；只保存最终转写。插话先停止播放/清旧轮再取消前台，后台独立。静音、隐藏、关闭、权限失败、退出均释放设备。Fish 保留 e4a66454f7a44f63a2cc9e8c044d701d 和用户选择 s2.1-pro-free，不自动换声/换档/云识别/逐句按键。

T1 在同机固定至少100条可再分发音频比较，覆盖普通话、台式口音、停顿、数字、中英和噪声。CER 恶化≤2个百分点，热 ASR P95≤旧版1.2倍；失败继续定位，技术门槛保持未通过，不保留 Python 冒充交付。
